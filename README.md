# Workflow Builder

A node-based diagram and workflow editor built with React, TypeScript, and Vite. Features smooth Bezier and Orthogonal connectors, typed port validation with cycle prevention, a pure command-pattern time-travel history engine, and JSON export/import.

## Requirements
- Node.js ≥ 18
- npm ≥ 9

## Getting Started

### Installation
```bash
npm install
```

### Development
```bash
npm run dev
```
Open [http://localhost:5173](http://localhost:5173) in your browser.

### Run Tests
```bash
npm run test
```

### Build Production Bundle
```bash
npm run build
```

### Type Checking & Lint
```bash
npm run lint
```
